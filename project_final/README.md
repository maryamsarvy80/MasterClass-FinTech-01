# German Credit Risk Analysis

## Project Overview
This project focuses on analyzing the German Credit dataset and exploring feature engineering techniques using Python and the Feature-engine library.

## Dataset
The project uses the German Credit dataset, which contains information about 1,000 credit applicants.

Dataset files:
- `german.data`: Original categorical dataset.
- `german.data-numeric`: Numerical version of the dataset.
- `german.doc`: Dataset documentation.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Feature-engine
- Jupyter Notebook

## Project Notebook
The main analysis is available in:

`project_german_credit.ipynb`

## How to Run
1. Clone this repository.
2. Install the required Python libraries.
3. Open the notebook using Jupyter Notebook or VS Code.
4. Run the notebook cells.
